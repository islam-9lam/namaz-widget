# Namaz Widget
Android-приложение с расписанием намаза, домашними виджетами и отображением следующего намаза на экране блокировки.

- Любой город через поиск Open-Meteo; после выбора расчёт работает офлайн.
- Локальный расчёт по координатам: Muslim World League и правило Twilight Angle для высоких широт.
- Оба варианта Асра — шафи и ханафи — с выбором для виджетов и AOD.
- Отдельные домашние виджеты 4×1 и 4×2.
- Расписание текущего и следующего месяца хранится на устройстве.
- Текущий/следующий намаз, обратный отсчёт и компас кыблы.
- Опциональная карточка AOD / Now Bar с системным обратным отсчётом.

## AOD и Now Bar

Переключатель внутри приложения запускает постоянное публичное уведомление со следующим намазом. На Android 16 оно запрашивает системный формат Live Update с `ProgressStyle`; на совместимых Samsung прошивка может показать его в Now Bar и на AOD. На более старых версиях Android используется обычная карточка экрана блокировки.

Экран приложения показывает фактическое состояние доставки: разрешены ли уведомления и Live Updates, отправлена ли карточка и получила ли она системный флаг продвигаемого постоянного уведомления.

Оформление Live Update контролирует Android / One UI: приложение задаёт название намаза, время, прогресс, цвет и иконку, но не использует произвольный `RemoteViews`. Кнопка «Убрать» отключает карточку прямо из уведомления.

## Сборка

Проект использует JDK 17, Android SDK 36, Build Tools 35.0.0, AGP 8.13.2 и Gradle Wrapper 8.13.

```bash
./gradlew testDebugUnitTest assembleDebug
```
