# Namaz Widget
Android-виджет времени намаза с отображением следующего намаза на экране блокировки.

- Москва по умолчанию.
- Umma.ru для обычных городов; Грозный — Govzalla.
- Кэш текущего и следующего месяца для офлайн-работы.
- Текущий/следующий намаз, обратный отсчёт и направление кыблы.
- Опциональная карточка AOD / Now Bar с системным обратным отсчётом.

## AOD и Now Bar

Переключатель внутри приложения включает постоянное публичное уведомление со следующим намазом. На Android 16 оно запрашивает системный формат Live Update с `ProgressStyle`; на совместимых Samsung прошивка может показать его в Now Bar и на AOD. На более старых версиях Android используется обычная карточка экрана блокировки.

Оформление Live Update контролирует Android / One UI: приложение задаёт название намаза, время, прогресс, цвет и иконку, но не использует произвольный `RemoteViews`. Кнопка «Убрать» отключает карточку прямо из уведомления.

## Сборка

Проект использует JDK 17, Android SDK 36, Build Tools 35.0.0, AGP 8.13.2 и Gradle Wrapper 8.13.

```bash
./gradlew testDebugUnitTest assembleDebug
```
